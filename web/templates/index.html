What you do with the downloaded zip

  1. Install Python 3.11 or newer from python.org. On Windows, tick "Add python.exe to PATH".
  2. Open a terminal (macOS: Spotlight → "Terminal" / Windows: Start → "PowerShell").
  3. Run:
    git clone https://github.com/{{ github_repo }}.git
cd ticketswap
  4. Unzip the file you just downloaded and drop .env and watches.json into that ticketswap folder.
  5. Install (macOS / Linux):
    python3 -m venv .venv
source .venv/bin/activate
pip install -e .
playwright install chromium
    (Windows: replace the first two lines with python -m venv .venv and .venv\Scripts\Activate.ps1.)
  6. Test:
    python -m ticketswap test-alerts
    You should get a WhatsApp on your phone within seconds.
  7. Log in to TicketSwap once:
    python -m ticketswap login
  8. Start watching:
    python -m ticketswap run
    Leave the terminal open. When a ticket appears, your phone buzzes. Tap the link, pay in the TicketSwap app.
